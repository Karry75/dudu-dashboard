# 设备预警看板 · 换电柜 / 电池（内网 ADB · 本地优先）

## 在线访问

- 本站看板（在线）：https://karry75.github.io/dudu-dashboard/
- 全部看板作品集（导航页）：https://karry75.github.io/dashboard-portal/

## 技术速览

- **形态**：单文件静态看板（HTML + JavaScript + ECharts），数据以离线快照形式随页面加载，纯前端渲染、无后端依赖。
- **原理**：业务库（阿里云 AnalyticDB）→ Python 抽取/构建管线 → 脱敏聚合快照 → 静态页面；页面打开即渲染，支持按维度筛选与下钻。
- **用途**：设备预警看板：换电柜与电池异常预警（P0/P1/P2 分级）。
- **脱敏**：公开发布版本已移除数据库连接信息、账号口令与个人敏感字段，仅保留聚合指标。


> ⚠️ **这是「设备预警看板」（换电柜 / 电池），与「深圳租车套餐台账」是两个完全独立的项目！**
> - **设备预警看板**：本项目目录 `dudu-dashboard`，双击本目录下的 `start.bat`，自动开 `http://127.0.0.1:8082`（或附近空闲端口）。
> - **深圳租车套餐台账**：另一项目，固定占用 `http://127.0.0.1:8081`。
> - 两者互不影响。如果你打开浏览器看到的是「深圳租车套餐台账」页面，说明你双击了**台账目录**下的 `start.bat`，或浏览器还开着 8081 的旧标签页。

> 运行范式对齐《租车协议台账·数据库连接与一键同步交付文档》：
> **对话触发同步 → 读本机配置 → 直连 ADB（只读）→ 落本地真相源 → 看板实时读盘**。

## 一、运行范式（5 个环节）

1. **对话触发**：你说「同步数据库 / 连内网同步」，AI 在你**本机** Bash 跑 `sync/sync_all.py`（也可双击 `start.bat` 或 WorkBuddy 自动化定时触发）。
2. **链接从哪来**：不是从对话解析，而是脚本 `json.load` 本机 `sync/db_config.json`（host/账号/密码全部在本机，**对话里不带密码**）。
3. **建立连接**：`sync_db.py` 用 `pymysql` 直连阿里云 ADB（utf8mb4，DictCursor，只读 SELECT，绝不写库）。
4. **落本地单一真相源**：同步结果写回项目根目录
   - `data.js` —— `window.TABLE_DATA = {...}`（前端直接 `<script>` 加载，看板真正读取的文件）
   - `data.json` —— 完整 JSON 镜像（便于脚本/工具读取）
   - 写盘前自动备份到 `sync/backups/`（保留最近 60 份），并写 `sync/sync_log.txt`
   - **幂等保护**：内容指纹比对，数据与上次一致则**不写盘、不刷新同步版本**，避免误覆盖
5. **看板自动生效**：`server.py` 由启动器**自动探测空闲端口**（优先 8082，主动避开台账占用的 8081），**每次 HTTP 请求都从磁盘实时读取 data.js（无缓存）**。改文件即生效，无需重启/重部署 → 浏览器硬刷新 `Ctrl+Shift+R` 即见。

## 二、首次使用（无需连库，先看页面）

**双击 `dudu-dashboard` 目录下的 `start.bat`** → 自动完成：
1. 定位本机 WorkBuddy 托管 Python `3.13.12`，注入 pymysql venv（无需 pip install）
2. 跑 `sync/sync_all.py`（若本机暂未连库，则保留样例数据，不会白屏）
3. 启动看板服务（**自动探测空闲端口，优先 8082，绝不占台账 8081**）
4. 自动打开浏览器，地址形如 `http://127.0.0.1:8082`（具体端口以黑窗口打印为准）

> 首次未连库时显示**样例数据**（电池 7 条 + 机柜 8 条），仅用于确认页面能正常打开。
> 黑窗口最后一行会打印：`★ 设备预警看板地址: http://127.0.0.1:<端口>`，认准这个地址。

## 四、端口与链接（已自动避开台账 8081）

| 项 | 值 |
|----|----|
| 看板地址 | `http://127.0.0.1:<自动端口，通常 8082>`（启动器黑窗口打印为准，**不是 8081**） |
| 端口分配 | 自动探测：优先 8082，若被占则 8083… 依次递增，**始终跳过台账 8081** |
| 手动指定端口 | `python server.py --port 8091` |
| 应急触发同步 | `POST /api/sync`（默认由对话/双击触发，无需按钮） |
| 健康检查 | `GET /api/health`（返回 `app: 设备预警看板（换电柜/电池）`，可用来确认没串项目） |

## 五、数据真相源与架构

```
阿里云 ADB ──本机内网──▶ sync/sync_db.py (pymysql 仅SELECT) ──▶ data.js (window.TABLE_DATA) + data.json
                                                                      │
                                           server.py :自动端口 实时读盘(无缓存) │ 读取
                                                                      ▼
                                                              浏览器 硬刷新即见
```

**铁律**
- 本地优先：数据全在本地文件，库停只停更新，已有数据不丢。
- 只读：同步脚本只 SELECT，绝不写库。
- 库不可达兜底：连不上不写盘，保留上次（或样例）数据。
- 端口隔离：本看板自动避开台账 8081，两者可同时运行互不干扰。

## 六、为什么你之前看到的是「深圳租车套餐台账」页面

| 想确认没串项目 | — | 访问 `http://127.0.0.1:<端口>/api/health`，看 `app` 字段是否为「设备预警看板」 |

## 七、编码坑说明（为什么 bat 改成了英文）

中文 bat 在 Windows CMD（GBK）下会乱码导致路径找不到、闪退。现 `start.bat` 为 100% ASCII，
所有中文 UI 放进 `_launcher.py`（强制 UTF-8 输出），从此不乱码。

## 八、运维

- 改 `server.py` 才需重启；静态文件每请求读盘，硬刷新即取最新。
- 凭证只存本机 `sync/db_config.json`，不进对话明文、不发布。
- 备份：`sync/backups/` 自动保留最近 60 份；日志 `sync/sync_log.txt`；同步指纹 `sync/last_sync_fp.txt`。

## 九、业务优先级（按你的口径，待首跑真实数据后由 AI 校准）

| 级别 | 类型 | 触发 |
|------|------|------|
| **P0** | 电池·无法识别 | comm_fail / identify_fail / offline |

| **P2** | 电池·饿死（电压耗尽） | 电压≤阈值 / 过放 |
| **P0** | 机柜·烟感告警 | smoke |
| **P0** | 机柜·水浸告警 | water |
| **P2** | 机柜·仓位告警 | slot / door |
| **P1** | 机柜·离线 | online_status = no_connected |
| **P1** | 机柜·弃用 | abandon_reason 非空 |
